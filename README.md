# FEU-inspired IT Portfolio

This is a beginner-friendly, one-page GitHub Pages website.

## Customize
1. Edit `index.html` and replace `YOUR NAME`, intro, descriptions, your actual roles, email, and project URLs.
2. Upload your portrait as `assets/profile.jpg`.
3. Upload your project screenshots as `assets/projects/pos.jpg`, `hiq.jpg`, `cinema76.jpg`.
4. Upload your certificate preview images (`certificate1.jpg`, etc.) and full PDF files (`certificate1.pdf`, etc.) under `assets/certificates/`.
5. Add more cards by copying an `<article class="card"> ... </article>` block.
6. Remove cards for which you don't yet have assets; example links are placeholders.

## Publish on GitHub Pages
Create a public repo, upload `index.html` and `assets/` at the root, then go to **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. View the link shown in Pages.

Images will be missing until you upload your own files matching the specified paths.
